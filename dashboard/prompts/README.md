# Prompts

Pasta para guardar os prompts usados no dashboard (análise de ferramentas, geração de modelos 3D
e outros). Um arquivo `.md` por prompt, com nome em português sem acentos
(ex.: `analise-ferramentas-3d.md`).

| Prompt | Imagem | O que recria |
|---|---|---|
| `MODELO-3D-REDE-NEURAL-01.md` | `MODELO-3D-REDE-NEURAL-01.png` | Orquestrador de agentes em anel, com log, decisões, status e P&L |
| `MODELO-3D-REDE-NEURAL-02.md` | `MODELO-3D-REDE-NEURAL-02.png` | Infográfico "1 agente no lugar de 25 assentos" |
| `MODELO-3D-REDE-NEURAL-03.md` | `MODELO-3D-REDE-NEURAL-03.png` | Painel de robô com toro 3D de partículas (Three.js) |
| `MODELO-3D-REDE-NEURAL-04.md` | `MODELO-3D-REDE-NEURAL-04.png` | Animação do infográfico 02 (usa a página do prompt 02) |

Os prompts usam nomes genéricos e dados fictícios, com aviso na tela, no lugar das marcas e dos
ganhos alegados nos reels de origem.
